# Great Barrier Reef Water Quality Monitor

Monitoring water quality in the Great Barrier Reef using remote sensing and geospatial analysis.

## Overview

This project monitors key water quality parameters in the Great Barrier Reef using satellite remote sensing data. It tracks changes in chlorophyll-a, turbidity, sea surface temperature, and other indicators of reef health.

## Tech Stack

- Python
- Google Earth Engine
- Sentinel-2 / Landsat 8
- QGIS
- Pandas, NumPy, Rasterio
